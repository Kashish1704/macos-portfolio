## Run Locally

Clone the repository:

```bash
git clone https://github.com/Kashish1704/macos-portfolio.git
```

Open the project folder:

```bash
cd macos-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
